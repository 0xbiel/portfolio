# 0xbiel Portfolio

This is my personal portfolio, built with [Next.js](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/). It showcases my projects, skills, education, and contact information.

## ✨ Features

- Modern, responsive design
- Project filtering by category
- Skills and tools overview with icons
- Education and certifications section
- Contact and social links
- Built with modular React components

## 🚀 Tech Stack

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- TypeScript

## 🛠️ Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/0xbiel/portfolio.git
cd portfolio
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## 📁 Project Structure

- `src/app/page.tsx` – Main portfolio page
- `src/components/ui/` – Reusable UI components
- `public/images/` – Project screenshots and icons

## 🖼️ Customization

- Add or edit your projects in `src/app/page.tsx`
- Update skills, education, and links in the same file
- Add images/screenshots to `public/images/`

## 📦 Deployment

Deploy easily on [Vercel](https://vercel.com/) or your preferred platform.
